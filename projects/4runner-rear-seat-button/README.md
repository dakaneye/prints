# 4Runner rear seat release button

Replacement for the small button that releases the rear seatbacks (the
fold-down button on the seat shoulder) on a 5th-gen Toyota 4Runner
(2010–2018). OEM part `72661-35010`. Pure download from Thingiverse — no
custom CAD on this one.

See `downloaded/SOURCES.md` for the URL, author, and license.

## Variants in the download

The author published two STLs:

- `Button_Not_Domed_Top.stl` — **revised version, recommended.** Top
  indentation removed for a cleaner top-surface print.
- `Button_Domed.stl` — original release; left in place for reference.

A Fusion 360 source file (`ButtonFusionPlans.f3d`) is also bundled if the
geometry needs tweaking for fit.

## Print recipe

| Filament | Print time | Notes |
|---|---|---|
| SUNLU PLA+ 2.0 grey | ~30 min | Grey is the closest match to the OEM dark-grey interior trim. Print the **Not_Domed** variant top-down (best surface up) so the visible face comes off the build plate clean. Small part — print one of each first to dial in fit before doing both seats. |

The button has a snap-fit tab; PLA+ should hold up to normal use, but
expect to reprint if it sees heavy use over years. Author notes the fit
is functional but "not perfect" — minor sanding may be needed.
