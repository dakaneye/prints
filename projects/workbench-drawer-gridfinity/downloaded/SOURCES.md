## Recommended starting points for tool drawers

These are go-to designs for the bin types a tool drawer needs. URLs
aren't linked here on purpose — fetch and paste them into entries above
as you download.

- **Generic bins (any cell size, configurable height):** Gridfinity
  Rebuilt on MakerWorld or via the kennetek OpenSCAD generator
- **Driver bit / hex bit holders:** search MakerWorld for "Gridfinity
  bit holder" — most cover 1/4″ hex bit shanks in 1×1 or 1×2 layouts
- **Hex key (Allen) sets:** "Gridfinity allen key" / "Gridfinity hex
  key" — angled cradle designs print without supports
- **Socket organizer rails:** "Gridfinity socket" — typically 1× rows
  with per-size pegs; 1/4″ and 3/8″ drive shapes are most common
- **Tape measure cradle:** "Gridfinity tape measure" — usually a 2×2
  cradle that holds the clip pointing up
- **Screwdriver holder (compact):** "Gridfinity screwdriver" — vertical
  pockets that index by tip size
- **Step bit / drill bit cradle:** "Gridfinity step bit" — held by the
  shank, tips up
- **Multi-tool / utility knife:** "Gridfinity utility knife" — slot or
  cradle depending on the knife style
