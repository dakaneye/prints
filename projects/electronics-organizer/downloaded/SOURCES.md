# Downloaded STL sources

**STL/3MF files themselves are gitignored** — only this SOURCES.md gets
committed. Do not re-host third-party models.

## Library: `gridfinity-build123d`

Bin geometry comes from the `moritzmhmk/gridfinity-build123d` Python
library (installed via `requirements.txt`, not as a downloaded STL). The
library generates Gridfinity-compatible bins and base profiles
parametrically; bins emitted by `bins.py` are derived from this code.

- **URL:** <https://github.com/moritzmhmk/gridfinity-build123d>
- **License:** MIT (verify on the repo)
- **Used by:** `3d/bins.py`, `3d/case.py` (for the Zone A baseplate cut)

## Drop-in third-party bins (optional)

The 3×3 bin set generated by `bins.py` is intentionally generic (single
open cavity per cell). If a specific item wants a purpose-shaped insert
(e.g., a cradle for the speakers, or compartment dividers for tact
switches), download the matching community bin and log it here. Match
the cell size in the spec — a 1×1 bin is 41.5 × 41.5 mm, a 1×2 bin is
41.5 × 83.5 mm.
