# Flexi articulated lion

Print-in-place articulated lion — joints come out moveable straight off
the bed, no assembly. Pure download from MakerWorld; no custom CAD on
this one.

See `downloaded/SOURCES.md` for the URL, author, and license.

## Print recipe

| Filament | Print time | Notes |
|---|---|---|
| SUNLU PLA+ 2.0 (oak wood, black, or white) | TBD — first print | Use **File → Open Project** on the creator's `.3mf` if MakerWorld provides one — it carries their tuned orientation, supports, and slicer settings for the print-in-place joints. Do **not** add a raft or supports between the joint segments — they'll fuse the articulation shut. |

Oak wood reads well on flexi animals; white shows the joint detail.
