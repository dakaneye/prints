# Spiral fidget (hexagonal)

Print-in-place spring-shaped fidget with a hexagonal cross-section.
Stretches, compresses, and twists in one hand. Pure download from
MakerWorld — no custom CAD on this one.

See `downloaded/SOURCES.md` for the URL, author, and license.

## Print recipe

| Filament | Print time | Notes |
|---|---|---|
| SUNLU PLA+ 2.0 (any color) | ~1.5–2.5 h | Print-in-place, no supports. Print orientation as the model is set up. Standard quality (0.2 mm). |
