# Icosahedron toy

Single-piece sculpted 20-faced polyhedron — tactile fidget object that
also rolls. ~65 mm across, roughly tennis-ball sized.

Intended use: toddler-friendly chunky shape for a 2.5-year-old to grip,
roll, and recognize as "the spiky ball." (Verified single solid, not a
20-piece assembly.)

See `downloaded/SOURCES.md` for the URL, author, and license.

## Print recipe

| Filament | Print time | Notes |
|---|---|---|
| SUNLU PLA+ 2.0 (white or oak wood) | ~2–3 h | Print on a flat face for best bottom finish; 0% infill is fine — the icosahedron's geometry is self-supporting and the empty interior makes it light. No supports. |
