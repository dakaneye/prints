## `icosahedron.stl` + `icosahedron.3mf`

- **URL:** <https://makerworld.com/en/models/524091-hyperhedron-icosahedron>
- **Author:** Claywood
- **License:** see MakerWorld page (verify before remixing or redistributing)
- **Downloaded:** 2026-04-22
- **Notes:** 65 × 65 × 65 mm sculpted icosahedron, single watertight body.
  The .3mf is the slicer-ready Bambu project; the .stl is the raw mesh.
  Despite the MakerWorld description mentioning "20 identical parts,"
  the file is a single solid — the 20 refers to the icosahedron's faces.
